- **Reason:** A proxy-equivalent (NUES Corporate Governance Report + Board's Report inside the Norwegian statutory Annual Report), aggregate compensation disclosure with a named incentive metric, a beneficial-ownership table (corroborated by a same-week Capital IQ cut), board composition/independence data, related-party disclosure, and a 5-year capital-allocation history (CIQ Financials workbook) are all present — so all six specialists can run, with two flagged sub-gaps (individual-executive pay detail; insider buy/sell transaction log) that narrow but do not block specific specialist reads.

- **Hard disqualifier already flagged by business-model/01_disqualifier-scan?** N — no disqualifier triggered. That scan separately flagged a genuine extraction gap (the printed Independent Auditor's Report text, pp.225-230, is missing from the pool's PDF extraction) as a data-completeness item to close, not an inferred qualification; convergent secondary evidence in the same filing supports an unqualified opinion.
- **Active partial-data caps:**
  - Shareholder friendliness capped at max 60 per MODULE_RULES "No ownership / insider-transaction data" row — the beneficial-ownership table is present and current, but no insider buy/sell transaction log (VPS primary-insider notifications / Oslo Børs managers'-transactions disclosures) exists anywhere in the pool.
  - Incentive alignment (agent 03) should treat CEO/named-executive individual pay as "Insufficient data" while still scoring the disclosed aggregate ELT total (NOK 88,952k FY2025), Board fees (NOK 7,873k), and the TSR ≥12% incentive metric — this is a narrower gap than a full "no compensation disclosure" cap and should not trigger the harsher max-50 cap, since real metrics and aggregate quantum are disclosed.
- **Critical missing items:**
  - Insider-transaction (buy/sell) data — no primary-insider notification log found.
  - Individual named-executive remuneration — the annual report explicitly defers this to a separate "Norsk Hydro ASA Report on executive remuneration 2025," which is not in the pool.
  - May 7, 2026 AGM voting/resolution results — the meeting had already occurred by this analysis date but its outcome (votes for/against the remuneration policy advisory vote, dividend approval, director elections) is not in the pool.
  - The printed Independent Auditor's Report text (pp.225-230 of the annual report) — an extraction gap already flagged by business-model/01_disqualifier-scan, not a governance red flag on its own.
- **Single highest-value missing document:** the standalone "Norsk Hydro ASA Report on executive remuneration 2025" (the individual-executive compensation/incentive detail the annual report itself points to).
